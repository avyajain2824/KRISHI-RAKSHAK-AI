
# 🌾 KrishiRakshak AI – Smart Farmer Dashboard

**KrishiRakshak AI** is a web-based farmer dashboard prototype designed to support farmers with crop-related information, farming guidance, weather updates, farm management, and agricultural resources.

The project aims to make farming information more accessible through a simple and user-friendly interface.

## 🚀 Features

- 🌱 **Crop Health Guidance:** Enter crop symptoms to receive basic keyword-based suggestions.
- 📸 **Crop Image Upload:** Upload and preview images of affected crops.
- 🤖 **AI Assistant Interface:** Provides a basic local keyword-based response system.
- 🌦️ **Weather Dashboard:** Displays sample weather information.
- 🗺️ **Farm Location:** Shows predefined farm locations.
- 👨‍🌾 **Farmer Dashboard:** Provides a central place for farming-related information.
- 🛒 **Supplier Section:** Designed for displaying agricultural suppliers.
- 🌍 **Multilingual Interface:** Supports multiple language options.

## 💻 How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

Alternatively, run a local server:

```bash
python -m http.server 8000
```

Open this address in your browser:

```text
http://localhost:8000
```

## 🌐 Deployment Using GitHub Pages

1. Create a repository on GitHub.
2. Upload all project files.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under Build and Deployment, select **GitHub Actions**.
6. Open the **Actions** tab.
7. Wait for the deployment workflow to complete successfully.
8. Open the published website URL from Settings → Pages.

## ⚠️ Current Project Limitations

This version is a front-end prototype.

- Crop suggestions use symptom keywords, not actual AI diagnosis.
- Uploaded crop images are not analysed by an image recognition model.
- Weather information is sample data, not live weather data.
- Login and account information are stored locally in the browser and are not secure authentication.
- The AI assistant uses a basic local response system.
- Supplier information needs to be connected to verified local dealers.

Do not use this prototype to store sensitive personal or financial information.
